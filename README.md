# Sistema de Gerenciamento de Estoque e Vendas

Bem-vindo ao **Sistema de Gerenciamento de Estoque e Vendas**, um projeto desenvolvido para facilitar o controle de produtos, movimentações, vendas e geração de relatórios para pequenos e médios negócios.

---

## 🚀 Funcionalidades

- **Cadastro de produtos** (nome, descrição, valor, quantidade )
- **Atualização automática de estoque** após cada venda
- **Registro de entradas e saídas** de produtos
- **Gestão de vendas** com cálculo automático do valor total
- **Relatórios** de faturamento e produtos com estoque baixo
- **API REST** para integração com outros sistemas
